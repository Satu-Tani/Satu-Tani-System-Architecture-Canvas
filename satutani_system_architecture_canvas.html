Menggambar Poligon Batas Lahan Petani

Koordinator Gapoktan masuk ke Web Portal Vue.js untuk mendaftarkan petani gurem. Menggunakan peta interaktif Mapbox/Leaflet, koordinator menggambar batas fisik sawah (poligon). Koordinat GeoJSON ditransmisikan ke Express.js dan diproses otomatis oleh PostGIS menggunakan perintah `ST_IsValid` dan `ST_Area` untuk menjamin luas bersih lahan dan mendeteksi data tumpang dian secara instan.
